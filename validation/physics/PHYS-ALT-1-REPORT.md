## A. Architecture and hull

A separate query instance contains exact retained Production lattice rows, paired
with their opposite indices. The original H0, omega, k, signs, band domain,
material-to-FFT conversion, 1/N² normalization and Coastal bake/formula are reused.
Temporal coefficients prepare once at the caller's Production simulation time.
The existing scalar and query-SIMD kernels then traverse only retained rows.
There is no spatial grid, producer, worker, snapshot queue or GPU readback.
The full direct authority's implementation is unchanged.

Hull points in meters (Water Race scene, 300 kg):

## B. Importance metric

With centered contact coordinates x/z, define normalized weights:

```text
w_heave[j] = 1/4
w_pitch[j] = (z[j] - mean(z)) / sum(abs(z - mean(z)))
w_roll[j]  = (x[j] - mean(x)) / sum(abs(x - mean(x)))
R_a(k,yaw) = sum_j w_a[j] exp(i k dot rotate(r_j,yaw))
```

The responses have unit L1-weight normalization and are averaged in squared
magnitude over 16 hull headings. For each opposite-index group g:

```text
E_g = sum_rows (parity * weight / N²)² (|H0(k)|² + |H0*(-k)|²)
V_height[g,a]   = E_g * mean_yaw(|R_a|²)
V_velocity[g,a] = omega² * V_height[g,a]
score[g] = sum_a V[g,a] / total_variance[a]   (six outputs)
```

Rank score per retained row. This minimizes the sum of expected normalized
squared errors across the six linear excitations. No wavelength cutoff, amplitude
boost, unrelated wave, or empirical compensation is applied.

An independent optimistic bound ranks groups by **heave variance only**. For
uniform spatial/heading and long-time sampling, omitted independent Fourier
variance gives RMS fraction sqrt(1 − captured variance). It is a spectral ensemble
bound for linear open-ocean heave, not a guaranteed error for each finite Coastal
trajectory or nonlinear force. Even that favorable rank misses the desired 5%.

there is no justified adaptive crossfade/hysteresis candidate to promote. It was

## M. Decision and comparison to the CPU FFT mirror

No tested K meets the heave/pitch/roll envelope. Current K512 has approximately
48.7% / 70.3% / 75.6% NRMSE; direction-specific fresh selection also fails.
Even heave-only optimal open-ocean expected omitted RMS is 42.8% at current K512.
The complete spectrum distributes meaningful hull excitation over many ordinary
LONG/MID modes. Four point contacts do not supply the hypothesized strong spatial
low-pass reduction. Their response is oscillatory, with pitch/roll and velocity
remaining important. The nonlinear force comparison does not rescue the hypothesis.

The requested experiment is therefore **BLOCKED by fidelity**, despite meeting
the sparse material-query performance targets. K512 is a diagnostic endpoint,
not a production recommendation; no convincing acceptable Pareto plateau exists.

| Property | CPU FFT mirror (previous measurements) | Sparse hull subset |
|---|---|---|
| Producer/preparation | ~9.21 ms per full physics snapshot | ~0.019 ms temporal preparation at K512 |
| Query | ~0.01 ms class | ~0.083 ms Coastal N4; ~0.028 ms at K128 |
| Fidelity | Full spectrum / validated lattice and sampled fields | Large measured hull and force error through K512 |
| Concurrency | Workers, buffers, latest-wins/freshness engineering | Synchronous O(K) temporal state; no producer scheduler |
| Latency | Explicit snapshot time/freshness | Evaluates supplied current time directly |
| Runtime weather | Versioned full configuration; remaining pipeline costs | Cheap retained-H0 blend; endpoint/renderer integration incomplete |

Those FFT timings are historical architecture measurements, not a rerun or an
identical-workload performance acceptance. The sparse branch does not alter the
FFT branch. Evidence favors retaining the full-spectrum CPU FFT architecture for
the existing four-point force model rather than promoting this sparse subset.
A future continuous hull-area or dynamic transfer filter would need its own
validated force model and experiment; it is not silently substituted here.
