# PHYS-GPU-1 authoritative resource audit

Starting source: `origin/wip/phys-opt-2`, `df4f5eca68c1d5918cd6bfd4e6f6cfb08c1260e7`.

`OpenOceanFFT._process` queues LONG, MID, SHORT `GPUStockhamFFT.dispatch` on the global render device. Each dispatch evolves the existing H0, runs the existing Stockham transforms, assembles maps, and ends its compute list. A query queued immediately after all three callbacks can consume those fields before the next ocean dispatch. No local device, duplicate spectrum, or additional ocean transform is needed.

Each solver owns RGBA32F displacement (`xyz = dx,height,dz`, `w = horizontal determinant`), RGBA16F normal, RGBA32F H0 (`H0(k).xy, conjugate H0(-k).zw`), and three double-buffered RGBA32F complex FFT images. The final spatial images are ping index 0 (two axes give an even stage count). Spatial A contains height and dx complex pairs; B contains dz and dxx; C contains dzz and dzx. The original implementation has no GPU velocity field. Resolutions/domain lengths come from `_wave_configs`, with MID resolution overridden by `_mid_resolution`; they must be recorded at runtime rather than inferred from defaults.

Production geometry samples `q / effective_domain + 0.5`. Manual equivalent: `fract(uv) * N - 0.5`, floor, positive periodic integer wrapping, and bilinear interpolation. This preserves the established `L/2-L/(2N)` material-q to FFT-q offset. Geometry uses hardware linear FFT/Field sampling and deterministic manual Warp sampling. The query uses deterministic manual bilinear equivalents for all fields, no camera/LOD fades. Effective domains and horizontal displacement use clipmap geometry scale; height uses ocean scale.

`get_underwater_medium_raster_sources` publishes the SAME displacement RIDs and borrowed Coastal Field/Warp RIDs used by the surface. Coastal textures are owned by `OceanCoastalRuntime`; borrowed RIDs must never be freed by query code. Field G is shoaling; A is validity. Warp XY is LONG material sampling coordinate, Z is determinant, W is validity. Clamp bilinear uses `clamp(uv,0,1)*N-0.5`. Query bounds use the Field rectangle, not the Warp rectangle.

Within the Field rectangle: `c = field.a * smoothstep(0,detj_safe,warp.z) * warp.w * edge`. `edge = smoothstep01(min(min(uv,1-uv)*(field_size-1)))`, one authored cell wide (PHYS-OPT-2I). LONG is `mix(LONG(q), LONG(warp.xy), c)`; its Y is multiplied by `mix(1,field.g,c)`. MID/SHORT sample q. The normal/determinant must describe this combined physical surface, including confidence/feather gradients. The CPU Mirror uses 0.01 m central differences when Coastal is enabled; open mode uses spectral derivatives.

Simulation time is `_wave_time`, advanced by simulation delta times speed multiplier. Pausing speed leaves it unchanged. Runtime weather currently uploads the native publisher's immutable H0 state in one render callback before the three band dispatches; this existing weather producer is not replaced in this phase. `_gpu_generation.get_runtime_spectrum()` carries config version, weather alpha/rate, choppiness/rate and spectrum time. Tags must be captured on the render thread after that upload, not copied from an earlier main-thread snapshot.

Global RenderingDevice already supports `buffer_get_data_async` in the existing LONG and breaker probes. The installed executable reports `4.7.1.stable.official.a13da4feb`; the new harness must also inspect its actual method signature. Official API reference: [RenderingDevice](https://docs.godotengine.org/en/4.4/classes/class_renderingdevice.html#class-renderingdevice-method-buffer-get-data-async). Async download delay follows the configured renderer frame queue; one physics tick is a measurement goal, not an assumed guarantee.

Current FFT resources represent only the last dispatched render time. A requested target time can be recorded and rejected when it does not match. Future-time support can schedule the SINGLE authoritative transform at a shared predicted time; current/future simultaneous fields would need a separately reviewed cost/lifetime design. PHYS-GPU-1 must not quietly generate a second ocean.
